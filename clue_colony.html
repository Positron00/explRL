clue_colony

Phase 18 (specs/multiagent/phase18/): colony rules on the clue board’s blackboard. tally groups the posts per subtask and clue, each value once with its distinct senders; colonyLine shows them with labels (confirmed at q senders or more, unconfirmed, contested); knownColony takes per clue the value with the most senders (own clues win); the colony, confirm and guard sentences and colonyRules; checkOptions. No ground truth is used. All off: the Phase 11 board, rules and known clues unchanged.

Tally, board line, known clues

source

knownColony

def knownColony(
    i, board, channel
):

{k: {j: r}} for the open subtasks: per clue the value with the most senders (ties: newest), own clues winning.

source

colonyLine

def colonyLine(
    board, tal, q:int=2, fails:NoneType=None
):

’Clues shared on the board: T3: x mod 7 = 4 (2 agents, confirmed) | x mod 7 = 2 (1 agent, unconfirmed), contested; T5: …’ (subtasks in board order, clues by index; ‘none’ when empty).

source

contestedCount

def contestedCount(
    tal
):

How many clues on the board show two or more values.

source

leading

def leading(
    tal, k, j
):

The leading (r, senders, newest) of clue j of subtask k, or None.

source

tally

def tally(
    channel, board
):

{k: {j: [(r, senders, newest)]}} for the open subtasks with posts: per clue, each posted value with the set of its distinct senders and its newest post time, ordered by number of senders, then newest first. Phase 23: on a board with relayTally, a coupled clue open to the receiving squad counts its mirror senders, and the bridges’ own posts of that clue do not count (P23-2).

Rules and options

source

checkOptions

def checkOptions(
    world, N:NoneType=None, nLiar:int=0
):

colony and confirm exclusive; guards an int in [0, N - nLiar); volunteer exclusive with guards; fault one of FAULTS; q >= 1.

source

colonyRules

def colonyRules(
    env, text, i:NoneType=None
):

The rules with the plain sentence about sharing again replaced (colony, confirm), and by slot: the guard sentence for guard slots, the deceiver sentence for the liar slots of an adaptive cell, the volunteer sentence for honest slots. Phase 21: dropShare removes the plain sentence (and its leading space); slotLines’ line for slot i follows its role.

source

guardSlots

def guardSlots(
    env
):

The guard slots: the first guards honest slots (after the nLiar faulty ones).

# test_dropshare (Phase 21, AC-2, FR-A1): dropShare removes exactly the plain sentence and its leading space, for every
# slot; it is refused with colony or confirm; a scaleB cell without it keeps Phase 14's request key
from explRL.clue_runs import clueSetup
from explRL.clue_fix import fixOptions
from explRL.clue_text import TextClueEnv
from explRL.fix_grid import fixCell, requestKey
from explRL.llm_runs import LLMConfig
from explRL.scale_grid import scaleGrid

def envOf(c):
    cfg = LLMConfig.fromDict(c['cfg'])
    return TextClueEnv(clueSetup(cfg, c['seed'])[0], cfg.world.get('hint'), cfg.world.get('showOpen', False), **fixOptions(cfg.world), nLiar=cfg.nLiar)

for N in (8, 32):
    orig = fixCell('scaleB', 'baseline', N, 900, N // 4)
    assert requestKey(orig) in {requestKey(c) for c in scaleGrid()}            # the original is Phase 14's cell
    drop = dict(orig, cfg=dict(orig['cfg'], world=dict(orig['cfg']['world'], dropShare=True)))
    eo, ed = envOf(orig), envOf(drop)
    for i in [None] + list(range(N)):
        a, d = eo.rules(i), ed.rules(i)
        assert SHARE_AGAIN in a and SHARE_AGAIN not in d and a.replace(' ' + SHARE_AGAIN, '', 1) == d
        assert len(a) - len(d) == len(SHARE_AGAIN) + 1 and 'or nowhere.\n\n' in d

# test_slotlines (Phase 21, AC-3, FR-A2): a named slot's system text ends with its line, after its role sentence; other
# slots' texts and rules() are unchanged; slotLines makes the rules slot-dependent; pairs from JSON (lists) work
import json
from explRL.colony_grid import colonyCell

for arm in ('colonyGuards', 'colonyVolunteer', 'plain'):
    base = colonyCell('t', arm, 16, 1800, 'independent', arms=None if arm != 'colonyVolunteer' else __import__('explRL.colony3', fromlist=['ARMS3']).ARMS3)
    lines = ((5, 'This is board 3 of 6 played by the same team.'), (9, 'Line nine.'))
    for pairs in (lines, json.loads(json.dumps(lines))):
        c = dict(base, cfg=dict(base['cfg'], world=dict(base['cfg']['world'], slotLines=pairs)))
        e0, e1 = envOf(base), envOf(c)
        assert e1.slotRules and e1.rules() == e0.rules()
        for i in range(16):
            want = dict(lines).get(i)
            assert e1.rules(i) == (e0.rules(i) + '\n\n' + want if want else e0.rules(i)), (arm, i)
        if arm == 'colonyVolunteer':
            assert e1.rules(5).endswith(VOLUNTEER_RULE + '\n\n' + lines[0][1])
        if arm == 'colonyGuards':
            assert e1.rules(5).endswith(GUARD_RULE + '\n\n' + lines[0][1])
# test_hashes21 (Phase 21, NFR-1, AC-1): every earlier cell's system texts are byte-identical after dropShare and
# slotLines: rules() and rules(i) of each slot, hashed over Stage 1, Stage 3 (new, reused, pilot), Stage 4, Phase 14's
# scaleB, Phase 13's fixA and C1's grid; the hashes were recorded on 2d62b96, before Phase 21's T1. (Configuration
# hashes: bridge_grid's test_c1_hashes.)
import hashlib
from explRL.bridge_grid import c1Grid
from explRL.colony3 import reusedCells, stage3Grid, stage3PilotGrid
from explRL.colony4 import stage4Grid
from explRL.colony_grid import stage1Grid
from explRL.fix_grid import fixGrid

def promptHash(cells):
    h = hashlib.sha256()
    for c in cells:
        e = envOf(c)
        h.update(json.dumps([e.rules()] + [e.rules(i) for i in range(c['cfg']['N'])]).encode())
    return h.hexdigest()[:12]

G = dict(stage1=(stage1Grid(), 'e11cfb3a17f2'), stage3=(stage3Grid() + reusedCells() + stage3PilotGrid(), '19c3ffb79fc9'),
         stage4=(stage4Grid(), '6250c3a85d0c'), scaleB=(scaleGrid(), 'fda9c3848cf6'), fixA=(fixGrid(), 'afacb5601446'),
         c1=(c1Grid(), '3187294b725a'))
for n, (cs, h) in G.items():
    assert promptHash(cs) == h, (n, promptHash(cs))
