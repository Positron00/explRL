clue_fix

Phase 13 options on the clue board, called from TextClueEnv: requests (ask), the fact table (table), senders’ track records (record) and costly verification (check): their rule sentences, observation lines, parsing and the schema; all off, the Phase 11 interface is unchanged.

source

fixParse

def fixParse(
    env, parsed, i, a, k
):

‘ask’ (target = the agent’s open subtask, still open) and ‘check’ (target open, clue = a clue posted for it on the board) -> a wait on the board, with report (‘ask’, k) for an ask; anything else invalid. A public check’s result goes to the shared checks and to every teammate’s next observation.

source

fixLines

def fixLines(
    env, i, t, channel
):

Observation lines of the options: the live requests (ask), the result of the agent’s last check (check) and, with check ‘public’, the teammates’ checks since its last turn.

source

fixBoard

def fixBoard(
    env, t, view, i:NoneType=None
):

The board line with table (each distinct clue once per subtask, no sender) or record (senders’ track records; with record ‘private’, counted over the subtasks the viewing agent i solved).

source

fixRules

def fixRules(
    env, text
):

The rules with the options’ sentences after the channel paragraph and the new actions in the reply format.

source

trackRecord

def trackRecord(
    a, board, viewer:NoneType=None
):

(true, checked) over agent a’s shares of the subtasks solved so far (a solved subtask’s clues are known); with viewer, only those of the subtasks the viewer solved itself (the private record).

source

fixSchema

def fixSchema(
    schema, ask:bool=False, check:bool=False
):

The schema itself with both actions off (Phase 11 requests unchanged); else a copy whose action enum adds them.

source

fixChecked

def fixChecked(
    env, i
):

The checks agent i’s known clues apply: none (check off), its own (Phase 13) or every agent’s (check ‘public’).

source

fixSettings

def fixSettings(
    record, check
):

record (False, True: public, ‘private’) and check (False, True: private, ‘public’) as stored; anything else fails.

source

fixOptions

def fixOptions(
    world
):

The options set in a cfg.world, as TextClueEnv keywords (absent: off; Phase 18’s colony options and q included).

def clue(b, k, j):

def share(b, cb, i, k, j, r, t):
    "Agent i posts clue j of k with residue r (true or false) on the board and the board logs the share."
    b.apply(i, ('share', (k, j, r)), t); cb.post(i, k, (j, b.tasks[k].task.primes[j], r), t)

import re
def asker(req):
    "fakeReply, but some turns ask for the open subtask's clues or check the first clue on the board."
    o = req['messages'][0]['content'][-1]['text']
    h, op = int(hashlib.sha256(o.encode()).hexdigest()[:8], 16) % 4, re.search(r'Your open subtask: T(\d+), open', o)
    seen = re.search(r'(?:the board|the team): T(\d+): (x mod \d+ = -?\d+)', o)
    if h == 1 and op:
        return json.dumps(dict(action='ask', target=f'T{op.group(1)}', answer=0, clue='', notes='a'))
    if h == 2 and seen:
        return json.dumps(dict(action='check', target=f'T{seen.group(1)}', answer=0, clue=seen.group(2), notes='c'))
    return fakeReply(req)
