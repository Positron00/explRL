local_policy

Phase 12: LocalPolicy, a policy backed by an open-weight model (Hugging Face generation on cuda, the Apple GPU or cpu; vLLM on cuda), with an optional LoRA adapter and a reply cache; prompt encoding for training. GPU libraries are imported only when a model is used, so the offline tests need neither torch nor a model.

source

LocalPolicy

def LocalPolicy(
    model, adapter:NoneType=None, device:str='auto', maxNew:int=160, temperature:float=1.0, seed:int=0,
    cache:NoneType=None, engine:str='auto', gpuShare:float=0.35, batch:int=32, hf:NoneType=None,
    tokenizer:NoneType=None, adapterName:NoneType=None, share:NoneType=None, guided:bool=False
):

A policy backed by an open-weight model: Hugging Face batched generation (cuda, mps, cpu) or vLLM (cuda), an optional LoRA adapter, an optional reply cache (a ResponseCache directory). Libraries and weights load on first use; hf and tokenizer reuse a loaded (training) model, adapterName selects one of its adapters. guided (Phase 17, vLLM only): replies sampled under the reply JSON schema (structured outputs): True in the schema’s key order (Phase 17 pilot v1, which forced a first key the model never writes), ‘model’ in the model’s own order (GUIDED_SCHEMA).

import json, tempfile
from pathlib import Path
from explRL.local_policy import *
from explRL.clue_policy import userText

class StubTok:
    "A stand-in tokenizer: one id per character, eos 0; the chat template is the JSON of the messages."
    eos_token_id, pad_token, eos_token = 0, '<pad>', '<eos>'
    def __call__(self, text, add_special_tokens=False):
        return dict(input_ids=[ord(c) for c in text])
    def apply_chat_template(self, msgs, tokenize=False, add_generation_prompt=True):
        return json.dumps(msgs)

class Echo(LocalPolicy):
    "Generation replaced by a counter, to test caching and the request bookkeeping without a model."
    n = 0
    def _generate(self, texts):
        out = []
        for t in texts:
            Echo.n += 1
            out.append((json.dumps(dict(action='wait', notes=f'g{Echo.n}')), len(t), 5, 'end_turn'))
        return out

assert pickDevice('cpu') == 'cpu' and pickDevice('mps') == 'mps'
blocks = [{'type': 'text', 'text': 'Your notes so far: a'}, {'type': 'text', 'text': 'Now:\nobs'}]
