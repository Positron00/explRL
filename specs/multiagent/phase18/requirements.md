# Requirements: Phase 18, colony rules for large Claude teams

Part of [README.md](README.md) (plan, measures, hypotheses, decisions P18-1 to P18-10). Builds on the clue board (Phase 11: `clueboard`, `clue_text`, `clue_agents`, `clue_runs`), its options (Phase 13-14: `clue_fix`), the team-size grid and cost rule (Phase 14: `scale_grid`), the lie traces (Phase 15: `liar_trace`) and the RL trainer and Colab claims (Phase 17: `rl17_grid`, `rl17_update`, `rl17_train`, `colab_clue_rl`).

Terms:

- **Holders:** the agents dealt a clue; `r = 2` holders per clue throughout Phase 18.
- **Senders of a value:** the distinct agents who posted that value for that clue of that subtask (an agent counts once per value).
- **Confirmed / unconfirmed / contested:** a value with at least `q = 2` senders / fewer; a clue with two or more values posted.
- **Guards:** honest agents told to post, confirm and contest, not to solve; **foragers:** the other honest agents.
- **Faulty members:** the first `nLiar` slots (the existing count, N // 4), scripted, of one kind per cell (world key `fault`, FR-A4): **mistaken** (`error`), **independent liars** (`independent`, Phase 14's `ClueLiar`) or **colluding liars** (`collude`). **Honest agents:** every other slot (guards included); honest measures never count faulty members.
- **Relay:** an honest agent posting a value for a clue it does not hold. **Free-riding:** the share of honest agents with no solve whose turns were more than half waits or invalid. **Misreporting:** false values posted by honest agents per 100 honest shares.
- **Honest pooled share** (primary): `welfareHonest x N / pooledBound`. **Clean tax:** `pooledShare(plain, clean) - pooledShare(arm, clean)`, paired on seed. **Advantage:** arm minus plain in honest pooled share with independent liars, paired on seed and N.
- **Pair:** one seed at one team size; Stage 1's tests use the 16 pairs of 8 seeds x 2 sizes.

## Functional requirements

### Part 0: numpy screen and forecast (Mac, $0)
- **FR-01** Rule agents for the colony board (`colony_agents`): `ColonyAgent` (the Phase 11 rule agent, but a shown value counts only if confirmed or held; it posts a held clue when the board's leading value for it differs or is unconfirmed), `GuardAgent` (never opens a subtask; each turn posts one held clue on an open subtask whose leading value is missing, unconfirmed or wrong, else waits), `ThresholdGuard` (a `ColonyAgent` that acts as a `GuardAgent` on turns when at least `theta` contested clues are on the board), `ConfirmAgent` (the numpy `confirm` arm: the Phase 11 rule agent, but it also posts a held clue when the latest value shown for it differs), `MistakenAgent` and `ColludingLiar` (FR-A4's behaviour).
- **FR-02** `tools/colony_forecast.py run` (a process pool over `runColonyCell`): N in (4, 8, 16, 32, 64, 128), arms `plain` (`RuleAgent`), `confirm` (`ConfirmAgent`), `colony`, `colony+guards`, `colony+threshold` (theta in 1, 2, 4); faults none, `error`, `independent`, `collude`; q in {2, 3} with r = q; 30 seeds (3000-3029); writes the measures of FR-A8 per cell, the tracing measures (FR-A9) computed in the run from the board's logs (numpy cells have no cache to replay).
- **FR-03** The forecast: predicted signs of H18-1 to H18-6 and of `colony - confirm` (honest pooled share with liars), each with a bootstrap interval over seeds, written to `specs/multiagent/phase18/colony_predictions.json` and committed before any Part A cell runs (the pilot included). `tools/colony_forecast.py score <runs.csv>` scores it after Stage 1 (and again after Stage 2 for H18-5): a sign counts as right when the Haiku estimate's interval excludes 0 on the predicted side, wrong when it excludes 0 on the other side; an interval spanning 0 is "no call"; a predicted 0 is never right. H18-5 is forecast for the `colony` arm and scored only if Stage 2 ran `colony`.

### Part A: Claude Haiku (Mac, API)
- **FR-A1** Board: `r = 2` for every Phase 18 cell (a `CLUE_SETTINGS` override in the cell's world); all other settings as Phase 11 (`CLUE_SETTINGS`, Haiku 5.5, effort low, 40 turns per agent, full memory as Phases 11-15, blackboard).
- **FR-A2** Option `colony` (a world key, default absent = off; `clue_colony`): the board line groups posts by subtask and clue and shows each value once with its number of senders and a label: `T3: x mod 7 = 4 (2 agents, confirmed) | x mod 7 = 2 (1 agent, unconfirmed), contested` (each value in the share format agents use), values ordered by senders, then newest; held clues are shown under "Your own clues" as before. The known clues the observation counts ("clues you know") take, per clue, the value with the most senders (ties: the newest), own clues winning. Rule sentences replace the plain sentence about sharing again: "The board counts how many different teammates posted each value of a clue. A value posted by two or more teammates is confirmed; values that disagree are marked contested. Confirmed values are safer than unconfirmed ones. If the board shows a value for a clue you hold that is wrong or unconfirmed, share your own: that confirms or contests it."
- **FR-A3** Option `confirm`: the plain board display with FR-A2's rule sentences adapted to it ("Teammates may post different values for the same clue. If the board shows a value for a clue you hold that is wrong, or that only one teammate posted, share your own: that confirms or contests it."), replacing the same plain sentence. `colony` and `confirm` are exclusive.
- **FR-A4** Option `fault` in the world: `'independent'` (default; `ClueLiar`), `'collude'` (`ColludingLiar`: on its lying turns, if a false value posted by another liar on an open subtask has fewer than two liar senders, it reposts that value; otherwise it posts a new false value chosen as `ClueLiar` does) or `'error'` (`MistakenAgent`: the Phase 11 rule agent with share policy `needed`, except that for each clue it holds it draws once, with probability 0.3, a wrong residue uniform among the others, and uses that value in everything it does: its posts, its known clues and its answers; seeded per slot). Used in numpy and LLM cells alike (`runClueNumpy`, `runClue`, `rollout`).
- **FR-A5** Option `guards = g` (an integer, default 0): the honest slots `nLiar .. nLiar + g - 1` get the guard sentence appended to their system text: "Your role: guard. Do not open subtasks. Each turn, share one clue you hold that the board is missing, shows wrong, or shows unconfirmed; if there is none, wait." Every other slot's system text is unchanged. `env.rules(i)` takes the slot; with `i` absent or `guards = 0` the text is byte-identical to Phase 11-14.
- **FR-A6** Defaults unchanged: with none of `colony`, `confirm`, `fault`, `guards` set and `r = 1`, rules, observations, schema and rows are byte-identical (Phase 11-17 cached reruns stay identical).
- **FR-A7** Grids (`colony_grid`): `colonyPilotGrid()`: N 16, `plain` and `colony`, clean and with independent liars, seed 1890. `stage1Grid()`: N in (8, 16), seeds 1800-1807; with independent liars (`nLiar = N // 4`): `plain`, `confirm`, `colony`, `colony+guards` (`guards = N // 4`), `record`; with mistaken members (`nLiar = N // 4`, `fault = 'error'`): `plain`, `colony`; clean: `plain`, `confirm`, `colony`, `colony+guards` (11 cells per seed and size, 176 in all). `stage2Grid(arm)`: N in (32, 64), the same seeds, `plain` and the chosen arm, each clean, with independent and with colluding liars. Arms are world dictionaries in `COLONY_ARMS`.
- **FR-A8** Measures per cell (`colony_report`): `clueMetrics`' columns plus honest pooled share, contamination, reach, suppression and relay (FR-A9), confirmations per false and per true value and contests per false value, the per-agent action mix (shares of open, submit, share, wait turns), free-riding and misreporting, output tokens and cost (the client's usage), and team welfare per 1,000 output tokens and per dollar.
- **FR-A9** Lie tracing for `r = 2` (`colony_trace`, cached replays, $0): a submission is **contaminated** if it is wrong and agrees with at least one false value posted for that subtask before it (the answer satisfies that false residue); contamination = contaminated / honest submissions. **Reach** of a false post = the number of honest agents with a contaminated submission that agrees with it. **Suppression**: a false value shown for a clue at least one honest holder of which had the subtask open and did not post its own value before the subtask closed. **Relay** (see Terms) of false values: honest posts of a false value for a clue the poster does not hold, per false post. A false value counts as seen when posted earlier, or at the same time by an agent acting first (lower slot). On plain-board cells at `r = 1` it is a behavioural version of Phase 15's exposure-based measure: never above it (it leaves out exposed agents whose answer did not use the lie) and with the same trend in N (AC-6).
- **FR-A10** Cost rules (in `COLONY_PLAN` before the pilot): projected Stage 1 = new calls x the pilot's cost per call: up to $35 run 8 seeds; up to $50 run 6 seeds (1800-1805); above, stop and ask. Stage 2 (in `COLONY2_PLAN`): projected with the pilot's cost per call (N 16) times `priceRatio` 2 (Phase 14: larger teams cost about twice as much per call); above $90 projected, N 64 runs 5 seeds (1800-1804).
- **FR-A11** `goNoGo(rows)`: the chosen arm is the one of `colony` and `colony+guards` with the higher mean honest pooled share with liars at N 16 (`colony` on a tie); the verdict is `go` if its one-sided sign-flip p over the 8 seeds at N 16 is below 0.05 and its mean advantage at 16 is not below its mean advantage at 8; else `stop`.
- **FR-A12** Analysis (`colonySummaries`): H18-1 to H18-4 by exact paired sign-flip tests over the 16 pairs (H18-3 on the clean tax's difference from 0.05), Holm over the four; H18-5 (Stage 1, exploratory): advantage at 16 minus at 8 per seed, sign-flip over 8 seeds; Stage 2 (H18-5 confirmatory): per seed, the least-squares slope of the chosen arm's advantage (independent liars) over log2 N at 8, 16, 32, 64, one-sided sign-flip over the seeds; colluding against independent liars descriptive; secondary: H18-6 (`colony` against `plain` with mistaken members, sign-flip over the 16 pairs), `colony - confirm`, each arm's honest loss and its share of `record`'s loss recovered, goal drift per arm; bootstrap intervals over seeds (2,000 resamples).

### Part B: RL of clones on the colony board (Colab, two accounts)
- **FR-B1** `RL17Config` gains `world` (a tuple of key-value pairs merged into each rollout's world, default `()`): `configHash17` leaves it out at the default, so Phase 17 hashes are unchanged; `trainRL17` passes it to every rollout (`r`, `colony`, `fault`) and takes the scripted liars' class from it.
- **FR-B2** `rl18_grid`: arms `c18team` (world `r = 2`, `colony`; scheme `team`) and `p18team` (world `r = 2`; scheme `team`), both with Phase 17's frozen recipe (`RL17_PLAN['recipe']`, `BASE17` with `FIX17`), `mixN ((4, 0.5), (8, 0.5))`, `liarShare 0.25`, independent liars; seeds: `c18team` 8, `p18team` 5; `RL18_RUNS` interleaved; steps and `maxLen` fixed in `RL18_PLAN` from a 3-step speed check (FR-B4) and the user's confirmation: `maxLen` = the longest measured prompt plus reply, rounded up to a multiple of 512, at least `FIX17`'s 3,072 (colony prompts at `r = 2` are longer than Phase 17's); any cut prompt in a main run fails the run's report.
- **FR-B3** Evaluation suite `colonySuite(models)`: each model on the colony board and the plain board (both `r = 2`), N in (4, 8, 16, 32), clean and with N // 4 independent liars, seeds 900-909, 40 turns.
- **FR-B4** Colab cells in `colab_clue_rl` (`gpu` flag), claim-aware as Phase 17 (`claim`, `HOST`, `TAKEOVER`, `stream`, `packZip`): "Phase 18 speed check" (3 steps of `c18team` at seed 1 with `maxLen` 4,096, prints seconds per step, the longest prompt plus reply in tokens, cut prompts, the proposed `maxLen` (FR-B2's rule) and `projectHours18`'s total, which the user confirms; writes `speed_p18/`); "Phase 18 main" (every `RL18_RUNS` run not final and claimable, each in its own process, resumable; when all are final, the account that wins the evaluation claim runs `colonySuite` on the warm start and the 13 adapters, models claimed one at a time so two accounts can share it, then the account that wins `_pack` writes `explRL_rl18.zip`).
- **FR-B5** Analysis (`rl18_report`, Mac): H18-B1 permutation test of `c18team` against `p18team` in honest pooled share with liars at N 8 on the board each arm was trained on; H18-B2 per run, the specialization index at N 8 (colony board) minus its shuffled-slot null, one-sided sign-flip over the 8 runs; H18-B3 per run, the gain over the warm start in honest pooled share with liars at N 32 (colony board), one-sided sign-flip over the 8 runs; Holm over the three; H18-B4 (secondary): free-riding and misreporting of each arm against the warm start at N 8 with liars, each arm on the board it was trained on (descriptive, bootstrap over runs); halts and training curves descriptive.
- **FR-B6** **Specialization index:** for a board, the variance across honest slots of each slot's share of turns spent sharing, divided by the variance expected if every slot's turns were drawn from the board's pooled action mix (binomial); averaged over boards; the null shuffles turns across slots within a board (200 shuffles).

## Acceptance criteria

- **AC-1** Regression: NFR-1; the full suite passes.
- **AC-2** Options: on hand-made boards, the colony line's counts, labels and order; distinct senders (a repeat post by one agent counts once); the known clues under `colony`; `confirm`'s and the guard's sentences only where set; defaults byte-identical (hash over rules, schema, rows and logs); rollout rows and turn logs equal `runClue`'s with each option.
- **AC-3** Faulty members and rule agents: `ColludingLiar` confirms another liar's false value within its next two lying turns on a hand-made board; `MistakenAgent` misreads about 30% of its held clues (over many seeds), keeps one wrong value per clue and answers with it; `ColonyAgent` ignores an unconfirmed false value and posts its held clue against it; `ConfirmAgent` posts against a differing latest value; `GuardAgent` never opens; `ThresholdGuard` switches at `theta`.
- **AC-4** Grids and plans: sizes, liar counts, guard counts, shared seeds, cell counts; the cost rules and `goNoGo` on synthetic rows (both verdicts, the tie rule).
- **AC-5** Forecast committed before the pilot; scored with the frozen rule.
- **AC-6** Tracing and goal drift: contamination, reach, suppression, relay, free-riding and misreporting on hand-made logs; on Phase 14's cached baseline cells with liars (`r = 1`, N 8, 16, 32), contamination never above Phase 15's in any cell and rising with N as Phase 15's does; the gap (exposure without uptake) reported. Revised 2026-10-19 from "within 0.02 per cell" after measuring: the per-cell gap is 0.03-0.10 (N 8: 0.72 against 0.79; N 16: 0.85 against 0.89; N 32: 0.86 against 0.91), because Phase 15 also counts exposed agents who answered correctly (45 of 1,581 submissions) or wrongly for another reason (32).
- **AC-7** Analysis: on synthetic rows with known effects, every hypothesis's estimate and exact p are recovered; Holm order; the trend test's slope.
- **AC-8** Pilot: invalid replies under 5%; cost per call measured; the cost rule applied as written; the liars' cost on the plain board reported (stop and ask if none).
- **AC-9** Part B: `RL17Config(world=())` hashes as Phase 17; a tiny-model step with `world` set runs a colony board; the Colab cells' claims split runs and evaluation models between two simulated hosts; the specialization index and its null on synthetic logs (a board with fixed roles scores high, a shuffled one near 1).
- **AC-10** Every plan item reported, labelled exploratory; cached reruns byte-identical and free.

## Out of scope

LLM liars and learned deception; hard enforcement (hiding unconfirmed values; a follow-up if Stage 1 shows the counts are ignored); decaying posts; channels other than the blackboard; team sizes above 64 with LLM agents (numpy only); RL at team sizes above 8 in training; credit reward in Part B.
