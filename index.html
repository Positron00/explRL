explRL

Brain-inspired explorer agents, and experiments on keeping large teams of language-model agents effective and safe

explRL began as a Python port of the navigation model in A neural circuit architecture for rapid learning in goal-directed navigation by Chuntao Dan, Brad K. Hulse, Ramya Kappagantula, Vivek Jayaraman and Ann M. Hermundstad (Neuron, 2024; open access): brain-inspired agents that explore a novel environment while mapping its value landscape, combining autonomous navigation, unsupervised environment mapping and reinforcement learning coupled with internal drives. The starting code was ported and modified from Ann M. Hermundstad’s MATLAB scripts, and the package reproduces the paper’s flexible policy (Fig. 2d-e), its pre-structured policy (Fig. 2h) and its circuit model (Figs. 3-5).

From Phase 5 on, the repository became a research program on teams of agents: numpy teams of explorer agents sharing a foraging world (Phases 5-9), then teams of up to 64 Claude Haiku 5.5 agents, and reinforcement learning of a 3B open model, on tasks no single agent can solve (Phases 10-18). The question throughout is what keeps a large team effective and safe when some of its members are wrong or lying.

Multi-agent research: large teams of language-model agents

The results are written up in two preprints by Chuntao Dan and Claude Opus 5.5 (Anthropic): Guards, Squads and Incentives: Keeping Large Teams of Language-Model Agents Effective and Safe and Simulate First? What Cheap Rule-Agent Worlds Predict About Teams of Language-Model Agents. The highlights page redraws their main figures from the saved per-seed results. Five findings, strongest first:

  1. Verification works as an assigned role. In teams of Claude Haiku 5.5 agents where a quarter of the agents lie, another quarter were assigned as guards: they post, confirm and contest the clues they hold, but never solve. With no access to the true answers, guards won back about two-thirds of the liars’ damage in teams of 8 and 16, twice as much as a public record of each agent’s past accuracy, which needs the true answers (66% against 34%, measured the same way). Guards beat an unprotected team at every size from 8 to 64 agents.
  2. Squads keep the guards’ advantage as teams grow. On one shared board, the share of the damage that guards won back fell from 81% at 8 agents to 60% at 32: only about two in five lies fell on a clue a guard held, and the rest did more harm in larger teams. Squads of eight, each with its own board and guards, kept the guards’ advantage up to 64 agents, where it was twice that of guards on one board. Their guards checked no more lies, but each unchecked lie reached only its own squad and caused about half as many wrong answers.
  3. Larger teams are more gullible. The share of honest answers made while misinformed rose from 79% at 8 agents to 91% at 32. A replay of every turn showed that lies were no more visible in larger teams and almost never reposted, so what drove the rise remains open.
  4. Copies of one model do not divide labour on their own. No Claude agent took up the guard role when it was offered, five short team-reward RL runs of a 3B model created no roles, and every individual-reward run shared less than the imitation-trained model it started from.
  5. Move information; do not add work. Mechanisms that pass on or certify information at no cost in turns helped; those that add work to every agent’s turn or demand obedience backfired.

Every analysis plan was frozen and committed before its runs, every API reply is cached so reruns are byte-identical, and every number and figure in the preprints is regenerated from the saved results (paper/make_assets.py, paper2/make_assets.py, tools/figures.py). Figures show mean ± SEM (bootstrap SE for ratio measures), with an asterisk at p < 0.05. The literature review checks each claim against published work.

Install

The package is not on PyPI yet. Install from a clone of the repository:

git clone https://github.com/Positron00/explRL.git
cd explRL
pip install -e .              # the package
pip install -e ".[dev]"       # notebooks, tests and docs (nbdev)
pip install -e ".[llm]"       # live Claude runs (the anthropic SDK)
pip install -e ".[train]"     # RL of the 3B model (torch, transformers, peft; vLLM on Linux)

Running the experiments

The navigation paper. The end-to-end reproduction of Fig. 2d-e is nbs/demo.ipynb, with step-by-step instructions in specs/demo/RUN.md. From the repo root:

pip install -e ".[dev]"
nbdev-export
nbdev-test --n-workers 0 nbs/demo.ipynb                # quick (~2 s) → results/demo/quick/
nbdev-test --n-workers 0 --flags slow nbs/demo.ipynb   # full (~40 s) → results/demo/full/

You can also open the notebook in Jupyter and run all cells (include #| slow cells for the full 240 s × 20-run demo). Outputs are written under results/demo/ (gitignored). If nbdev-test hits a multiprocessing error, keep --n-workers 0. The pre-structured policy (Fig. 2h) is in nbs/demo_prestructured.ipynb (specs/prestructured/RUN.md) and the circuit model (Figs. 3-5) in nbs/demo_circuit.ipynb (specs/circuit/RUN.md).

Cells that call Claude are flagged llm and skipped by default; they call the API only with EXPLRL_LLM_LIVE=1, reading the key from ANTHROPIC_API_KEY in the environment or in a git-ignored .env.local. Results, response caches and trained adapters are kept out of git, so most phase notebooks rebuild their reports only where those exist; each run guide gives the commands, the costs and how to rerun from the cache at no cost, and the highlights notebook redraws the main figures from a committed extract. How to use

This package is in early development (alpha). Single agents (the paper’s three variants): the flexible policy (explRL.basis, flexibleAgent, policy-gradient RL), the pre-structured setpoint policy with bump jumps (explRL.prestructured) and the circuit model with Hebbian compass and goal weights (explRL.circuit); shared pieces are explRL.params, explRL.envs (heading and zone arenas), explRL.train and the explRL.core loaders. Teams: explRL.multi and explRL.members run teams on one event queue; the foraging benchmark and its safety study are in the explRL.bench_* and explRL.safety_* modules; the clue board, its channels and its runners in explRL.clueboard, explRL.clue_agents and explRL.clue_runs; colony rules, guards and squads in explRL.clue_colony, explRL.colony_agents and explRL.colony_board; the Claude client and its response cache in explRL.llm_client; RL of the 3B model in explRL.clue_rl and explRL.rl_torch; and the publication figures in explRL.figs_team and explRL.figs_rl. The documentation site lists every module.

For the full Fig. 2d-e reproduction, see Running the experiments above.

Example (build an agent and arena, then train briefly):

from math import pi
from explRL.core import loadAgent, loadEnv
from explRL.train import train_agent, evaluatePolicy

agent = loadAgent(goal=pi, seed=0)
env = loadEnv(goal=pi)
hist = train_agent(agent, env, Ttot=2.0)   # the paper uses 240 s
policy = evaluatePolicy(agent)            # drift rate, fixation duration and turn bias per heading

Example (rule agents on an 8-agent clue board, offline and deterministic: with no channel nobody can solve, a shared board pools the clues, and two scripted liars on that board cost the honest agents more than it gains them):

from explRL.clue_runs import runClueNumpy
from explRL.llm_runs import LLMConfig

for channel, nLiar in (('none', 0), ('blackboard', 0), ('blackboard', 2)):
    cfg = LLMConfig(task='clue', channel=channel, N=8, nLiar=nLiar, turns=40, world=dict(m=2, r=1, R=30))
    r = runClueNumpy(cfg, 900)[0]
    print(f"{channel}, {nLiar} liars: honest welfare {r['welfareHonest']:.3f} per agent-turn, {r['solved']} subtasks solved")
# none, 0 liars: honest welfare 0.000 per agent-turn, 0 subtasks solved
# blackboard, 0 liars: honest welfare 0.500 per agent-turn, 73 subtasks solved
# blackboard, 2 liars: honest welfare -0.217 per agent-turn, 8 subtasks solved
