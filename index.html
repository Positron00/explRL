explRL

A repo for brain-inspired AI agents that explore novel environments and map their value landscapes

This package builds brain-inspired AI agents that simultaneously explore novel environments and map their value landscapes. It integrates autonomous navigation, unsupervised environment mapping and reinforcement learning coupled with internal drives. The starting code is ported and modified from MATLAB scripts (Ann M. Hermundstad) described in this publication: A neural circuit architecture for rapid learning in goal-directed navigation. Chuntao Dan, Brad K. Hulse, Ramya Kappagantula, Vivek Jayaraman, Ann M. Hermundstad. https://doi.org/10.1016/j.neuron.2024.04.036. (open access)

Install

The package is not on PyPI yet. Install from a clone of the repository:

git clone https://github.com/Positron00/explRL.git
cd explRL
pip install -e .

Running the demo

The end-to-end reproduction is in nbs/demo.ipynb. Step-by-step instructions: specs/demo/RUN.md.

Install dev dependencies, then run from the repo root:

pip install -e ".[dev]"
nbdev-export
nbdev-test --n-workers 0 nbs/demo.ipynb          # quick (~2 s) → results/demo/quick/
nbdev-test --n-workers 0 --flags slow nbs/demo.ipynb   # full (~40 s) → results/demo/full/

You can also open the notebook in Jupyter and run all cells (include #| slow cells for the full 240 s × 20-run demo). Outputs are written under results/demo/ (gitignored). If nbdev-test hits a multiprocessing error, keep --n-workers 0.

Pre-structured policy (Fig 2h): nbs/demo_prestructured.ipynb and specs/prestructured/RUN.md.

Circuit model (Figs 3-5): nbs/demo_circuit.ipynb and specs/circuit/RUN.md.

How to use

This package is in early development (alpha). It implements three variants from the paper: the flexible policy (explRL.basis, flexibleAgent, policy-gradient RL), the pre-structured setpoint policy with bump jumps (explRL.prestructured), and the circuit model with Hebbian compass and goal weights (explRL.circuit). Shared pieces: explRL.params, explRL.envs (heading and zone arenas), explRL.train, and explRL.core loaders.

For the full Fig 2d-e reproduction, see Running the demo above.

Example (build an agent and arena, then train briefly):

from math import pi
from explRL.core import loadAgent, loadEnv
from explRL.train import train_agent, evaluatePolicy

agent = loadAgent(goal=pi, seed=0)
env = loadEnv(goal=pi)
hist = train_agent(agent, env, Ttot=2.0)   # the paper uses 240 s
policy = evaluatePolicy(agent)            # drift rate, fixation duration and turn bias per heading
