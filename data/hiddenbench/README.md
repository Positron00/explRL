https://huggingface.co/datasets/YuxuanLi1225/HiddenBench (licence: MIT, as declared on the dataset card).

Source paper: Yuxuan Li, Aoi Naito, Hirokazu Shirado. *Systematic Failures in Collective Reasoning under Distributed
Information in Multi-Agent LLMs* (HiddenBench). ICML 2026. https://arxiv.org/abs/2505.11556. Evaluation suite:
https://github.com/Yassellee/HiddenBench_ICML.
