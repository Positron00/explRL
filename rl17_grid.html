rl17_grid

Phase 17 (specs/multiagent/phase17/): RL that makes larger teams pay off. The team-size evaluation grid (teamSizeSuite) and step 0’s models; RL17Config (constrained replies, clipped passes per batch, mixed team sizes with liars, pilot v3’s value-token loss and per-token clip) with configHash17 (Phase 12-16 hashes unchanged); the pilot (PILOT17, PILOT17_PLAN, pilotChoice), the main arms and runs (RL17_ARMS, RL17_RUNS, RL17_PLAN, rl17Config), run claiming across Colab accounts (claim) and the main-run cost projection (projectHours).

pilotConfig

def pilotConfig(
    name, model, out, recipe:NoneType=None
):

A pilot run (r17mix’s mix, seed 1, 30 steps); p17d needs the recipe it extends (turns 40).

source

rl17Config

def rl17Config(
    arm, seed, model, out, recipe, steps:int=60
):

An RL17 run: RL_PLAN v2 + BASE17 + the recipe + the arm; trainSeed = seed - 1; a checkpoint every step (a step takes many minutes and a Colab session ends after about 24 hours; the interval is not part of the configuration hash).

Claiming runs across Colab accounts

source

claim

def claim(
    runDir, host, takeover:tuple=()
):

Claim runDir for host (claim.json): free -> claimed; ours -> True; another host’s -> False unless the run’s name is in takeover. A folder with progress but no claim (a run started by a cell without claiming) counts as held by another host. The write is atomic (temporary file, then rename) and read back.
